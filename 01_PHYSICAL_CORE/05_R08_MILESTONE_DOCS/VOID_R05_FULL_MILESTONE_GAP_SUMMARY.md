## What is already built and must not be reimplemented
- M00–M12 DACB: historical C/Nim/ISA etc remains provenance-archived in original releases; its tested software mathematics are *not* a physical analog computer. Do not copy production C into VOID.
- K01–K04 share one active passive RC mesh; source variants are intentional controls rather than four competing computational cores.
- K05 is the one active physically realizable DC weighted-sum fixture, corrected in R04, including external meter loading and five inputs.
- Existing raw physical evidence TSVs, original source ZIPs, instrument connection matrix, and all historical R01–R04 releases stay unchanged.

## Roadmap by domain, with genuine gaps
- M00–M12: preserve DACB mathematics/ISA/software and existing tests; no automatic VOID hardware promotion.
- M13–M30: cybernetics, sound, I/O and comparison programs are historical/future projects. VOID's current two-node bench circuit does not embody them.
- M31–M45: physical census and K05/K03 circuits have partial design coverage (M31, M37–M39, M43–M44); most physical performance, acoustic, closed-loop and replication requirements lack real device runs.
- M46–M65: Q²/polyform and SNN references remain heritage research. M51–M54 have partial design correlations to the noise diode, two-node mesh and K05; actual physical RBits (M55), multilevel stabilized states, physically demonstrated novel operations and a cybernetic loop have no physical implementation evidence.
- M66–M85: observables and evidence source types documented. Neither a measured finite Koopman model nor the hypothetical infinite projector has been built. No two-control geometric phase hardware is wired.
- M86–M115: R04 advances archival preservation and K01–K05 physical circuit design, not the external fabrication/measurement prerequisites M88–M99. Mesh has **no L** device, so M93 resonant RLC is absent. Finsler M100–M103, Holonomy M106–M109, ultrametric M110–M112, and physical RBits M113 have no supporting physical evidence; M114 independent active interlock is also not built.

## Critical path, without redundant branches
Existing K05 physical fixture → real K05 instrument evidence → K01–K04 source/control physical evaluation → two-node simultaneous dynamics → Gate K observed finite operator test if warranted. Separate science threads (F/H and multilevel memory) should not be silently merged into this source design. A gate's outcome cannot supply empirical measurements for another physical mechanism.

## Existing working program versus proposed physical machine
A verified netlist is a hardware design; an electrically measured device produces raw calibration/data/energy evidence. The package **does not contain** a verified fabricated physical VOID device. That is a missing external experiment, not a claim that creative analog hardware cannot be made. Nominal circuit references are retained for comparison only.

# Physical multilevel RBits and SNN-like coupled dynamics — VOID R05 source audit

**Determination from actual active circuit files:** The VOID mesh contains only passive resistors/capacitors with two simultaneously responding nodes (`PROBE_A`, `PROBE_B`). A resistor/capacitor state is analog and continuous; assigning `I`, `V`, `X` names does not produce independently restorable, metastable physical levels. No physical RBit, qudit, quantum code, energy-minimizing multistable cell or SNN firing/refractory state is wired into K01–K05. The historical DACB/NeuroMantle software routines are not converted into physical behavior merely by retaining their archives.

## What the physical device already does as a topology
The real current-limited diode junction can excite the existing **passively coupled** RC mesh through `C_ACBLOCK`, and the two outputs share real conductance/capacitance coupling; K05 separately expresses two linear weighted sums through resistors. These are separate *test fixtures* under one VOID physical architecture, not independent software forks. The impedance and dynamical response are physically defined by component values; there is no self-sustaining active switching oscillator or stable 3-or-more-level memory in the specified active network.

## Physical multilevel acceptance, without character encoding
Test distinct persistent or naturally identifiable material states *only* if a physically accessible component offers multistability, e.g. an independently characterized hysteretic/threshold device. Define the actual electrode variables, continuous control signal, state lifetime, state separation relative to instrument/thermal noise, write-and-read disturbance, drift/temperature, bias energy, and complete passive/active power accounting. Capture paired simultaneous measurements from coupled cells under common physical excitation to determine cross-state causality, not a sequential CPU scan presented as a physical process. An SNN-like physical model would require measured coupled integrate/trigger/reset or other explicitly characterized continuous state transition, not the software SNN implementation.

## How to evaluate multilevel scaling without symbol magic
A measured cell with n reliably distinguishable states has at most log2(n) *nominal* bits of ideal state-label capacity, not demonstrated exponential processing speed. For C coupled cells the naive combinatorial label count n^C does **not** imply independent, controllable, reliably read states or exponential computational benefit. Account for measured read/write error, bandwidth, retention, interactions, and energy. The Roman-style I/V/X glyphs are optional notation for measured device states, not physics and not software qubits.

## Current engineering order
Keep existing Gate K circuit and K05 wiring as the sole active design. Establish physical output, transfer characteristics, and two-node covariance from the existing mesh first. After there is calibrated device evidence, choose ONE genuinely nonlinear/multistable physical component for an explicit causal study, measured under an independent control. Do not invent a parallel working implementation, source of fictitious traces or an on-die device map.

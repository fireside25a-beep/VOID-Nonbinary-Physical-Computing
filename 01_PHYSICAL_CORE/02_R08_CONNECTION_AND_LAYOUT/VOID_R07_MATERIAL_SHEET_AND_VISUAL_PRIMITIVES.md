## Native physical primitive — no character code, encoded weight, quantum token or individual digital neuron

Eight equal nominal force-sensitive or variable-resistance material sites form a real 2 × 4 resistive **sheet**. Each neighboring site is connected by the physically specified 22k resistors. Two distant sheet terminals expose continuous FIELD_A and FIELD_B potential; they influence the same existing coupled RC mesh and charge capacitors. The phenomenon is electron flow and charge transport through conductance and capacitance. The pads have no letter, number, ternary sign, binary code or numeral assigned. Multiple contacts act concurrently on the sheet without an algorithm scanning them one at a time. Their spatial placement is a real material topology; no precomputed symbol-to-voltage table encodes letters.

Two real mechanically variable three-terminal 10k wipers couple motion/position into the same shared field. Two protected analog BOUNDARY_A/B nodes accept physical electrical input from actual bench-specified sensor/DAC equipment. These nodes contain only resistor bleed, clamp diode and 470k coupling cards, not assumed MMIO addresses or software execution sequences.

The same material network contains existing K05 five-electrode conductance, reverse-biased physical junction route, the shared two-node RC network, 10mH inductor with 10nF capacitor/resistance branch, and now three interacting capacitor charge-state primitives CHARGE_A/B/C. Two anti-parallel real diode components provide direct nonlinear physical state interaction. The three charge voltages are continuous degrees of freedom, NOT three RBits and NOT a demonstrated multi-stable neural cell.

The physically driven output interface has four independently conductive BJT/LED light-element sites, an analog X–Y–Z instrument electrode set and two resistor-isolated piezoelectric capacitance sites. BJT/LED currents come from a separately counted 3.3V source; this is a real analog optical-output *schematic*, not a text LCD panel, an artificial code decoder, software framebuffer or a physically tested board. X–Y output requires an actual high-Z powered display device. Piezo source cards are nominal electrical models; identify actual mechanical ceramic parts before assembly.

## Causal I/O shape and engineering focus

Physical force/contact/motion + actual electrical boundary -> continuous sheet potentials -> shared RC/K05/junction network -> coupled charge/diode dynamics -> independent LED currents, X–Y voltage and piezo charge. The material supplies state transitions; a CPU's instruction or entropy routine is NOT the computational engine. Historical DACB RDRAND/RDSEED execution proves only the recorded CPU instruction-level entropy path; no invented wiring from CPU internal junctions to these specific material terminals is asserted.

Potential development toward a complete text input and visible text output is pursued **from physical input/transform/display primitives and tested physical task behavior** rather than assigning letters to resistors or inventing a language runtime. The implemented display primitives show material observables only. Further high-density optoelectronic display matrices, state addressing, stateful material adaptation and useful semantic decoding are separate physical capabilities to build and measure; they are not hidden in this circuit.

## Direct physical operator
The local state is simultaneous **charge**, **voltage**, **current** and **coupling**, rather than one or more encoded bits. The shorthand `I`, `V`, `X` names concurrent electrical quantities: injected current, voltage on a capacitor, and exchange current between adjacent nodes. They are **not Roman-numeral values**, memory words, output characters or Boolean states. Three capacitors `CHARGE_A`, `CHARGE_B`, `CHARGE_C` share reciprocal resistor couplings, local leakage, cross-feedback, one antiparallel diode conduction path and the already-existing inductor/resistor/capacitor link between the shared mesh ports. No separate per-bit handling, clock, random-number emulator or software timestep is part of the material network.

## Input field
Eight individual force sensors form a 2-row, 4-column resistive sheet. Each force-dependent physical resistor is **the same nominal released-state element**, each has the same 1k guard and 220k return. Ten 22k nearest-neighbor resistors couple the material sites. A physical contact at one location changes a local conductance, and physical current redistributes through the sheet before influencing `FIELD_A/B`, mesh `PROBE_A/B` and capacitor states. This is a material spatial input field, NOT one analog letter code per key. Two mechanical axis-potentiometers also affect the same mesh and charge networks. Another pair of physically protected analog electrical inputs can be used for DAC/sensors; no arbitrary host MMIO address is embedded in the circuit.

## Physical output and display
Four independent LED+2N3904+emitter-resistor current branches draw from the isolated 3.3V output rail. A/B are modulated from `CHARGE_A/B`; C/D from `FIELD_A/B`. They can operate concurrently as one primitive four-site analog light field; this is **not** a text/graphics framebuffer or a symbol encoder. Three voltage headers `DISPLAY_X`, `DISPLAY_Y`, `DISPLAY_Z` expose the actual A/B/C charge nodes through 100k sensing paths and nominal 10M instrument input equivalents, for a high-Z scope or material display controller. Two 15n ceramic piezo equivalents and 100k isolation paths are physical electromechanical output terminal candidates. Actual brightness, movement and display behavior are evaluated on real components.

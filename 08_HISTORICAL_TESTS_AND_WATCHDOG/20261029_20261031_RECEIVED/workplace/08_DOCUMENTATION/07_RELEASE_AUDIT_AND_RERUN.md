# VOID / HX89 — Independent execution and release audit

## One executable machine, not nine versions

`00_CONTROL/run_canonical_release.py` executes the existing full source paths sequentially. It uses `00_CONTROL/run_whole_machine.py`, original HX89 native execution, the repaired EntropyAVX derivative, real x86 CPU batch and cache/history probes, actual reversible **digital** lattice-gas execution, emitted HX89 Polyform and feedback to the next native CPU workload, plus the cross-core material-memory falsification attempt. Historical source snapshots and source archives are kept exclusively for provenance and repeatability; they are **not alternate active machines**.

Source identity and milestone acceptance are deliberately separate. The complete M00–M115 historical milestone ID sequence is preserved, but it does not mean 116 physically realized hardware milestones.

## Reproduction without manual trace editing

From the restored `workplace/` directory:

```sh
python3 -S 00_CONTROL/repair_restored_native_build.py
python3 -S 00_CONTROL/run_canonical_release.py --repeat 2 --cycles 4 --material-blocks 2
```

The first command rebuilds native EntropyAVX after relocation, preserving stale absolute-path CMake build directories. The second command performs **sequential** whole-machine runs with unique evidence directories and bounded subprocess execution. The exclusive-build guard disallows overlapping runs. Repeated identical command parameters mean identical test design, not identical noisy physical timings.

### Scheduler-contaminated CPU interventions

On a virtualized processor, a 20 ms physical CPU stimulus may be descheduled long enough that its actual elapsed time exceeds the predeclared acceptance window. That is **not** valid acquired data. The cross-core experiment permits at most six new independent acquisitions **only** for the exact `stimulus not acquired at requested wall-time` failure. Each rejected CSV, stdout and stderr is saved unchanged with hashes and its rejection reason. No retry is triggered by weak effect size, unexpected signal sign, lack of statistical significance, or unfavorable physical conclusion. Accepted CSVs, independent HX89 outputs and original source hashes are checked again during verification. Exhaustion fails closed.

### What the instrumentation really establishes

| Mechanism | Real executed evidence in the tree | Missing independent physical proof |
|---|---|---|
| RNG | RDRAND/RDSEED CPU-visible conditioned words | Raw silicon thermal noise function readback and control |
| SIMD | Native scalar/AVX2/AVX-512 interventions | Nonbinary material operation performed by that stimulus |
| Cache | Native loads, cache eviction, measured timing | Separable continuous analog state, nonlinear operator |
| Power and temperature | Workload-dependent timing and processor state-history attempts | Independently calibrated die-local temperature/power/current readout |
| HX89 | 5D, Q², reversible **digital** gas, generated Polyform, native feedback | Physically continuous execution substrate |
| K06 / AC–DC | Preserved physical circuit netlists and library includes | Assembled physically coupled network with measured charge/current and three-level write/hold/read |

The scientific acceptance rule is not discretionary: a known CPU-executed digital controller and native workloads cannot themselves certify physically nonbinary computation. In particular, the finite C lattice gas is software, even if fully reversible and actually executed.

## Build completeness and source protection

The complete older 301 MB research archive is not omitted: it is reconstructed exactly from the two preserved original byte halves and verified against its SHA-256. The kit reassembler validates ZIP CRCs, module SHA-256, file-by-file SHA-256, directory inventory and executable modes. Keep the downloaded ZIPs, source manifest and restoration kit together. Do not overwrite the source archives with reformatted files.

## Physical classification

Hardware actual: real processor instructions, memory/cache coherence, TSC counters and CPU affinity; physical cache state has material implementation. Semantic feedback: host digital representation, the digital HX89 executed machine and digital C reversible gas MODEL. The work **does not** establish independent analog on-die measurements, controllable MOS weak-inversion currents, a new continuous many-body state machine or assembled K06 electrical path. No new physical multilevel memory acceptance is promoted. Entire experiment ran on a KVM-presented Intel Xeon Platinum 8573C vCPU; no independent calibrated on-die temperature or DC-rail measurements were captured. Analog, acoustic, DRAM retention, oscillator and thermodynamic mechanisms are listed as physical candidates, not evidenced as completed integrations.

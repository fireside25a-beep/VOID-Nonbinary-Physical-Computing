# VOID / HX89: seven-layer engineering evidence register

## Principle

There is exactly one source-authoritative K06 R08 circuit, one versioned native HX89/CPU controller and **two explicit input/output backends**: (a) source-derived numerical reference, currently executed and digitally tested, and (b) a physical material/analog DUT with actual instrument acquisition and protected stimulus. No modeled voltage is repackaged as a physical observation. This is a staged research-to-prototype release, not a represented manufactured semiconductor product.

## Physical module sequence with one common controller

**K06 CORE**: actual R/C/L/D/Q continuum including charge nodes and source-linked K05/material instances. **P1 POWER**: independently current-limited 24 V K01 bias and isolated 1.8/3.3 V rails, plus separately correct bipolar K05 excitation. **P2 OBSERVATION**: initial real calibrated meter connection, then qualified guarded FET buffer. **P3 HOST STIMULUS**: current-limited measured WRITE/BOUNDARY excitation, with a future attached ADC/DAC transport after genuine device testing. **P4 MATERIAL**: eight independent contacts, eight fixed series 1 kΩ parts, 22 kΩ sheet coupling and actual two-axis potentiometers. None of these modules is a fictional digital analog device.

The seven layers are tracked independently because passing a native software regression is neither a PCB design-rule check nor a measured hardware experiment. The low-cost bench prototype only needs verified discrete parts, short low-leakage connections, a suitable current-limited power source and a calibrated instrument. Do not inflate the initial build with a mandatory four-layer PCB or nominal Class 3 assembly.
